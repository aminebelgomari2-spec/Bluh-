Guide GitHub Pages & Fichiers 3D

Pourquoi le joueur ne tombe plus à travers la map

1. Structure exacte à la racine de GitHub

Vos fichiers doivent se trouver au même niveau que index.html :

📁 votre-depot/
├── index.html
├── map.glb (Votre carte 3D)
├── player.glb (Votre avatar 3D optionnel)

2. Système de Sécurité Anti-Chute

Si map.glb n'est pas encore téléchargé ou introuvable, le script crée instantanément un monde procédural de blocs solides avec des plateformes. Le joueur est toujours replacé en toute sécurité sur le sol le plus haut.
