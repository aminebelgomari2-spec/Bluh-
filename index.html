Guide des Modèles 3D & GitHub Pages

Comment personnaliser votre univers Roblox web

1 Où télécharger des modèles 3D compatibles (GLB/GLTF) ?

Pour que le jeu fonctionne sans ralentissement, téléchargez vos fichiers au format .glb ou .gltf sur ces plateformes gratuites :

  • Sketchfab (Recherchez des packs low-poly gratuits, ex: "Low Poly Terrain" ou "Roblox Avatar")
  • Kenney.nl (Modèles 3D libres de droits parfaits pour les jeux blocs/arcade)
  • Poly Haven (Pour des décors environnementaux)

2 Comment nommer et placer les fichiers à la racine ?

Dans votre dépôt GitHub, déposez vos fichiers à la racine (exactement au même niveau que votre fichier index.html) :

📁 votre-depot-github/
├── 📄 index.html (Le code du jeu)
├── 📄 map.glb (Votre décor / carte 3D)
├── 📄 player.glb (Votre personnage 3D)

Note : Si les fichiers GLB ne sont pas trouvés, le jeu crée automatiquement un monde procédural de secours (cubes/sol géométrique) pour éviter les plantages.

3 Contrôles du jeu

Sur PC :

• Z Q S D ou Flèches pour se déplacer

• Espace pour sauter

• Clic glissé pour orienter la caméra

Sur Mobile :

• Joystick tactile virtuel en bas à gauche

• Bouton rond à droite pour sauter

• Glissement tactile sur l'écran pour tourner la caméra
